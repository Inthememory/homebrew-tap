# Vusion Intelligence Tap

## How do I install these formulae?

`brew install Inthememory/tap/<formula>`

Or `brew tap Inthememory/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "Inthememory/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew&#39;s documentation](https://docs.brew.sh).
